# Pizzeria Colombianita

Aplicación de escritorio y web para la gestión de una pizzería (pedidos, cocina, clientes, combos, inventario y caja). Cliente hecho con Angular y empaquetado con Electron.

El servidor está en [Colombianita_Java_Oracle](https://github.com/Colombianita-App/Colombianita_Java_Oracle).
